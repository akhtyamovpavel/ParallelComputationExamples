# CUDA Streams и Events

Авторские примеры идут от измерения времени к копированиям и перекрытию:

- `00-events-timing`: сравнение CPU-таймера без ожидания, CPU-таймера с ожиданием GPU и CUDA events.
- `01-async-memcpy`: обычная и pinned host memory, асинхронная постановка копирования с ожиданием завершения для измерения.
- `02-overlap-compute-copy`: авторские worker streams и legacy stream 0. Его неявные зависимости нужно учитывать при изменении режима default stream.
- [Стенд порядков выдачи](03-overlap-orders/README.md): baseline, interleaved и batched с явными событиями завершения для nonblocking streams.

Подписи GB/s старых примеров используют деление на 1024 в третьей степени, то есть GiB/s. Разные streams позволяют выдать независимую работу, но не гарантируют фактического перекрытия на любом устройстве.
