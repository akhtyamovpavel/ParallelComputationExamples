# Минимальные исправления Scan

Основные примеры в соседнем каталоге исправлены по конкретным ошибкам. Здесь сохранены отдельно применимые поясняющие копии:

- `00-naive_scan_cpu.cpp` сохраняет исходный CPU-цикл и измеряет его через std::chrono::steady_clock, затем проверяет каждый префикс.
- `correct_scan_barrier.cu` добавляет безусловный барьер после каждого уровня down-sweep.
- `correct_scan_barrier.patch` показывает изменение относительно прежнего авторского correct_scan.cu. В текущем основном файле барьер уже присутствует, повторно применять patch не требуется.

Копии не добавляют глобальные смещения или поддержку произвольного хвоста. Полный массив и хвост показаны в [стенде глобального Scan](../05-global-scan-compaction/README.md). История Git сохраняет прежние версии примеров; исходники записи отдельно сохранены в учебном комплекте.

CPU-копию собираем из текущего каталога:

```bash
g++ -O2 -std=c++17 00-naive_scan_cpu.cpp -o scan_cpu
./scan_cpu
```
